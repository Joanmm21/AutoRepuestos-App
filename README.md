AutoRepuestos-App

Descripción del proyecto:
AutoRepuestos-App es una aplicación móvil desarrollada en Android para la gestión de una tienda de repuestos de automóviles.

Tecnologías utilizadas:
Aplicación Android:
Kotlin
Android Studio
XML
Firebase Authentication
Retrofit
Kotlin Coroutines
Backend y base de datos:
Node.js
Express.js
API REST
MySQL

Estructura del repositorio:
android/: código fuente de la aplicación Android.
backend/: código fuente del servidor Node.js y API REST.
manuales/: manual de usuario y manual técnico en PDF.
