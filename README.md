#  AutoRepuestos-App

##  Descripción del proyecto

**AutoRepuestos-App** es una aplicación móvil desarrollada en Android para la gestión de una tienda de repuestos de automóviles.


##  Tecnologías utilizadas

### Aplicación Android
- Kotlin
- Android Studio
- XML
- Firebase Authentication
- Retrofit
- Kotlin Coroutines

### Backend y base de datos
- Node.js
- Express.js
- API REST
- MySQL

##  Estructura del repositorio

- **android/**: Código fuente de la aplicación Android.
- **backend/**: Código fuente del servidor Node.js y API REST.
- **manuales/**: Manual técnico y manual de usuario en PDF.
- **README.md**: Información general y documentación del proyecto.
